## 命名与登记约定

- **编号开头**（`05-`、`06-`、`07-`、`08-`）：历史 v1.11.x 工作；
- **日期开头**（`YYYY-MM-DD_*`）：记录真实工作日期的任务书、验收和待议清单；索引按日期倒序；
- 新主文档头必须有**记录日期、四位版本、审批状态、代码基线**；一环完成后补验收证据和交付 commit，不把待审批方案标成已验收；
- 同一开发轮次的文档、调整说明与验收共用版本；下一轮按游戏口径更新 / 功能模块增改 / bug 修复的规则递增，不因多个 commit 或修文档错字自动跳号；
- 待议文档须标为「待议、未排期」，不得作为开工授权；获准后再新建任务主文档并登记下一位版本。
