## 命名与登记约定

- 文件以 `YYYY-MM-DD_主题.md` 命名，日期为真实工作日期；索引按日期倒序。
- 新主文档头必须有**记录日期、四位版本、审批状态、代码基线**；验收后补验收证据与交付 commit，不把待审批方案标成已验收。
- 同一开发轮次的文档、调整说明与验收共用版本；下一轮按游戏口径更新 / 功能模块增改 / bug 修复递增，不因多个 commit 或修文档错字跳号。
- 待议文档须标「待议、未排期」，不得作为开工授权；获准后新建任务主文档并登记版本。
- 已结案的历史文档可合订略缩，原文保留在 Git 历史（`git log --follow` / `git show <commit>:<路径>`），不在索引中逐份保留。放弃的方案直接删除，不留待议条目。
